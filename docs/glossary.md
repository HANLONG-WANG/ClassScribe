# ClassScribe 术语表

| 术语 | 稳定含义 |
|---|---|
| 课堂工作台（`classroom_workbench`） | 对最长约 90 分钟课堂音视频执行可恢复、可追溯的离线批处理并直接导出的产品形态。 |
| IBus 听写（`ibus_dictation`） | Fedora/IBus 下低延迟、可持续分块的语音输入产品形态；不加载模型的薄引擎连接本地守护进程。 |
| 语言模式 | 仅指 `zh`、`ja`、`en`、`auto_mixed` 四个稳定值；`auto_mixed` 同时允许片段级识别与语言切换。 |
| 自动最佳（`auto_best`） | 从注册表候选中选择主模型；初始默认由公开事实引导，稳定选择由本机 gold benchmark 决定。 |
| 手动主模型（`manual_primary`） | 用户指定主模型，但质量门仍可调用备用模型复核。 |
| 严格单模型测试（`strict_single_model`） | 只运行指定模型、禁止 fallback 的可复现评测模式，不等同于普通手动选择。 |
| 忠实层（`faithful`） | 与音频证据直接绑定的转录；不得被语言模型自由改写。 |
| 智能纠正层（`corrected`） | 在不覆盖忠实层的前提下，通过有来源的术语规则等生成的派生文本。 |
| 用户层（`user`） | 用户编辑结果；必须保留它与此前文本层的关系和差异。 |
| canonical timeline | 全系统唯一的时间坐标：16 kHz 音频的 int64 sample index，区间采用半开形式 `[start_sample, end_sample)`。阶段 1 实现。 |
| 候选 | 某个已绑定真实音频区间的模型输出，携带模型、版本、置信度／质量信息。 |
| 共识 | 仅在对齐后的短片段或词级候选之间作出的可追溯选择；不是长字符串相似度投票。 |
| 质量门 | 自动检测循环、静音幻觉、语言脚本、异常字符、置信度及时间轴异常，并决定接受、复核或标记听不清。 |
| fallback／复核 | 质量门触发的备用模型处理；在 `manual_primary` 中允许，在 `strict_single_model` 中禁止。 |
| 听不清标记 | 以当前语言呈现并包含真实起止时间的显式占位符；它表示系统拒绝编造。 |
| gold benchmark | 由本机课堂和听写样本、人工确认参考文本及分层指标组成的稳定选模依据。 |
| 正式推理 | 从输入音频到转录、说话人、对齐、质量决策、文本处理和导出的运行时路径；必须完全本地。 |
| 主动模型操作 | 用户明确发起的模型安装或更新；这是唯一允许联网的产品操作，与正式推理隔离。 |
| 人工阻塞 | 任务必须等待用户点击、校正或批准才能完成／导出的状态；课堂自动流水线禁止这种依赖。 |
