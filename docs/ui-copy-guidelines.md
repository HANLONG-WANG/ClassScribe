# ClassScribe 界面措辞规范

本规范适用于 WebUI、IBus 菜单、CLI、导出提示、安装器和文档。界面测试应检查关键
语义，而不只检查控件是否存在。

## 必须使用的产品语言

- 将两个产品入口命名为“课堂转录”和“IBus 语音输入”，不能合并成无上下文的
  “转录模式”。
- 语言选项固定显示为“中文”“日语”“英语”“自动／混合”。
- 模型选项固定显示为“自动最佳”“手动主模型”“严格单模型测试”。
- 选择“手动主模型”时必须说明：“质量检查仍可能使用备用模型复核。”
- 选择“严格单模型测试”时必须说明：“不会调用备用模型；结果适合模型评测，可能
  低于自动流水线质量。”
- 课堂校对入口使用“可选校对”，不能出现“完成任务前必须校对”之类措辞。
- 文本视图明确标为“忠实转录”“智能纠正”“用户编辑”，并能查看层间差异和来源。
- `auto_best` 必须区分“初始推荐”和“由本机基准校准”；不能用厂商数据暗示它必然
  是用户录音上的最佳模型。

## 不可靠内容

不可靠区间只能显示下列语言专用格式；`start` 和 `end` 必须替换为真实的
`HH:MM:SS.mmm` 时间：

- 中文：`［听不清 {start}–{end}］`
- 日语：`［聞き取り不明 {start}–{end}］`
- 英语：`[inaudible {start}–{end}]`

不得使用没有时间范围的省略号、猜测文本或貌似完整的模型补写来隐藏未知内容。

## 隐私措辞

推荐固定说明：

> 转录在本机完成。ClassScribe 默认不联网，不上传音频、文本、课程词典或日志。
> 只有你主动安装或更新模型时，模型管理器才会访问网络。

“本地”不能被描述成“优先本地但必要时云端回退”。模型缺失时应提示用户显式安装，
正式推理不得自动下载。

## 准确率与限制

允许：“自动质量检查会标出低置信度和重叠语音区间”“质量取决于录音条件和本机
模型校准”。

禁止以下措辞及其同义变体：

- “100% 准确”“零错误保证”“任何录音都完美识别”；
- “重叠语音保证逐字归属正确”；
- “厂商榜单第一，因此在你的课堂上必然最好”；
- “AI 会自动补全听不清的内容”。

## 自动完成语义

“完成”表示自动流水线已生成可直接导出的当前最高质量结果，不表示零错误。质量门
无法可靠采用内容时，应产生带时间范围的听不清标记；不得为了消除警告而编造文本。
