# ADR-0002：正式推理完全本地

- 状态：已接受
- 日期：2026-09-03
- 关联：`PRD-PRIV-*`

## 背景

音频、转录、课程词典和诊断日志可能包含敏感课堂内容。隐式模型下载也会破坏离线
可复现性。

## 决策

正式推理进程默认不得发起外网请求，也不得包含云端 fallback 或遥测。缺少模型时
必须安全失败并指向独立模型管理操作。只有用户明确发起安装或更新时，该隔离操作
才可联网；已安装模型必须固定版本并可在断网环境验证。

## 后果

离线完整测试是每阶段默认验收条件。网络客户端不得成为 core、dictationd、IBus
engine 或推理 worker 的运行时依赖。诊断与日志不得上传，并须遵守本地最小披露。
