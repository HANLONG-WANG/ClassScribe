# ADR-0003：以音频证据和文本分层保真

- 状态：已接受
- 日期：2026-09-03
- 关联：`PRD-TEXT-*`、`PRD-QUAL-004/005/006/007`、`PRD-PRIN-001/002/003/006/007`

## 背景

未对齐的长文本投票、浮动时间点和生成式补写会产生无法审计的“漂亮但不忠实”结果。
标点、术语纠正和用户修改如果覆盖原文，也无法回溯错误来源。

## 决策

任何候选必须先绑定真实音频区间。共识只在自然边界内的短片段、对齐词之间执行；
优先保留模型原生时间戳和置信度，强制对齐只能处理已通过质量门的结果。分别持久化
`faithful`、`corrected`、`user` 文本层及差异。自动采用的每个词必须来自具体模型
候选或确定性术语规则。无法可靠识别时输出带真实范围的语言专用标记。

## 后果

不得用长字符串相似度投票，不得让 LLM 自由改写忠实层，不得在标点处理中改变词语。
导出可以选择文本层，但不能删除来源、质量决策或历史层。
