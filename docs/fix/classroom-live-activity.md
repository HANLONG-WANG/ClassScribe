# 课堂任务实时活动

任务页分为总体流程、当前操作和实时详情。总百分比仍为检查点完成度；字节、音频时长、窗口、片段和导出文件分别报告，不用于虚构模型内部百分比或预计剩余时间。

## 数据契约

- `activity` 是当前检查点活动快照，包含 `run_id`、检查点 ID、尝试次数、阶段、操作、操作开始时间和实际进展时间。
- 模型调用依次报告资源等待、文件校验、环境准备、加载、处理、释放。校验量来自 SHA-256 读取循环；文件计数只在校验通过后增加。
- FFmpeg 标准化使用 `-progress` 的真实输出音频时间。语言及结构处理报告窗口范围和编号；正文、复核、对齐报告片段范围与编号；导出报告实际写入文件数。
- 不支持内部进度的模型报告不确定状态、RPC 超时阈值、耗时和每秒进程存活观测。观测不会刷新 `progress_at`，重复计数也不会。
- `stage_counts`、`stage_activity` 与 `events` 用于阶段列表和可读记录。进程心跳不会冲掉最近的操作记录。

## 生命周期与开销

活动通过上下文变量跨异步调用及 `asyncio.to_thread` 传递，直接进入内存事件总线，不等待检查点事务提交，不新增数据库写入。连续计数约每秒发布一次，操作边界和最终计数立即发布。SSE 重放、最近事件与各阶段活动记录均按任务限长。

暂停、取消和检查点完成/失败会清除当前活动；旧运行标识不能覆盖新检查点。浏览器恢复最近任务 ID，快照恢复当前活动。SSE 带序列号重连，检查连接超时与心跳缺失，保留轮询备用。历史终态事件不会截断重试任务的新事件；终态由任务快照判定并停止监听。

活动记录属于服务进程内状态。页面刷新保留；服务重启后由已有持久检查点恢复流程并重新报告活动，不把重启前的“校验中”当作当前状态。

## 验证

回归覆盖真实字节读取、校验失败文件计数、计数合并、心跳与实际进度区分、未提交事务内的快照可见性、旧尝试隔离、模型生命周期、SSE 重放/重连/服务序列重置以及页面终态清理。浏览器验收覆盖桌面与手机宽度、刷新恢复和默认折叠的技术详情。
